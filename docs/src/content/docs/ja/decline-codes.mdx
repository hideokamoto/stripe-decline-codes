このライブラリは、Stripe の
[カード拒否コード](https://docs.stripe.com/declines/codes?locale=ja-JP) の表に記載されている
すべての拒否コードをカバーしています。Stripe が返す可能性のある非推奨
（deprecated）のコードも含まれており、表の末尾にまとめて表示されます。

検索ボックスでコードや説明文による絞り込みができ、ドロップダウンでソフト /
ハード拒否のカテゴリでも絞り込めます。**ソフト拒否**は一時的なもので、リトライ
すると成功する可能性があります。**ハード拒否**は恒久的なもので、自動的に
リトライすべきではありません。
